# 🏦 Banking Database

A beginner SQL project created using MySQL Workbench to practice database creation and management concepts.

## 📌 Project Description

This project contains a banking database designed in MySQL. It was created to learn and practice:

- Database Creation
- Tables
- Primary Keys
- Data Types
- SQL Queries
- Database Management using MySQL Workbench

## 🛠️ Technologies Used

- MySQL
- MySQL Workbench
- SQL

## 📂 Project Files

```text
Banking_DB/
│
└── Banking_Database.sql
```

## 🚀 How to Run

1. Open MySQL Workbench
2. Import the SQL file
3. Execute the script
4. Explore the database structure

## 🎯 Learning Objectives

- Understand relational databases
- Practice SQL syntax
- Learn database design concepts
- Build a foundation for advanced SQL topics
